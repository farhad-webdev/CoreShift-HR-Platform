# CoreShift landing page

A responsive HR SaaS landing page based on your reference screenshot. Built with plain HTML, CSS and JavaScript for VS Code.

## Run it
1. Extract the ZIP.
2. Open the `coreshift-website` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code **Live Server** extension and click **Go Live**.

## Customize
- Change the brand and page text in `index.html`.
- Colors, layout and responsive breakpoints are in `style.css`.
- Menu, testimonial slider and demo form behavior are in `script.js`.

## Notes
- Icons use Lucide (CDN), not emojis.
- Photos load from Unsplash, so an internet connection is needed for those images and Google Fonts.
- The contact form is a front-end demo only. Connect Formspree, a backend, or another form service to receive real submissions.
